# Manet 设计规范 V1.0

> 所有 UI 设计与调整必须先对照本文档。冲突时以本文档为准；
> 确需突破时，先更新本文档，再改代码。
> 气质关键词：**克制、安静、书卷、理性秩序**——深夜图书馆，而非喧嚣的效率机器。

## 1. 品牌基调

- 产品名 **Manet**（拉丁语 *manet*：它留下 / 它仍在）。品牌语句：*Quod manet, manet.*
- 品牌标记 `i-mark`：**半圆落日 + 音波波纹地平线**——地平线不用直线，
  以起伏的声音波纹换形承载落日；仅两个元素，纯线稿、与图标系统同网格同线宽。
  禁止写实日落风景插画。标记色默认复古棕；favicon 同形。
- 侧栏导航顺序与命名：**设定 / 任务 / 存档**（设定在前，存档为内容库）。
- AI 人格不出现于界面功能名（功能叫「AI 解读」等），人格仅存在于产品叙事。
- 不做复古Cosplay：不用羽毛笔、古书、蜡封、羊皮纸纹理等具象元素；
  古典气质只通过**比例、线条、字体、留白**体现。
- 避开：科技蓝、霓虹、渐变、大色块、麦克风/播放键等具象品牌图形、emoji。

## 2. 色彩

| 角色 | 色值 | 用途 |
|---|---|---|
| 页面背景 | `#F7F5F0` 暖白 | body / 详情页底 |
| 侧边栏 / 播放栏 | `#F0EEE7` 象牙白 | 常驻结构面 |
| 内容面 | `#FFFFFF` | 转写/面板/弹窗卡片 |
| 主文字 | `#292824` 墨灰 | 标题、正文 |
| 次文字 | `#858176` 灰褐 | 标签、说明、次级按钮字 |
| 弱文字 | `#ABA69A` | 元数据（日期/时长/时间戳） |
| 强调 | `#806B50` 复古棕 | 主按钮、激活态、链接、角标、品牌标记 |
| 强调浅底 | `#EFEBE1` | 选中底、正文高亮 |
| 悬停底 | `#F2EFE7` | 行/按钮 hover |
| 分隔线 | `#E4E0D7` | 所有 1px 线 |
| 边框（输入） | `#C6BFAE` | 输入框/复选框描边 |
| 成功 | `#6E8B5E` | 完成状态 |
| 进行 | `#9A7B2F` | 运行中状态 |
| 危险 | `#A6503C` | 错误、删除 |

规则：
- 每屏色彩 ≤ 4 族；棕色只用于**少量强调**，不做面积填充（主按钮除外）。
- 状态色只出现在状态符号（圆点/图标/左色条），不做大面积背景。
- 深色面（视频区）上的控件用暖白 `#F7F5F0`（`.on-dark`）。

## 3. 字体

| 用途 | 字体 | 备注 |
|---|---|---|
| 功能界面（按钮/标签/输入/元数据） | 无衬线：`-apple-system, "PingFang SC", …` | 默认 body |
| 中文正文（转写稿/随笔/札记/摘要/章节） | 宋体：`"Songti SC", "Noto Serif CJK SC", …`（`--serif`） | 行高 ≥ 1.9 |
| 品牌字标 / 目录标题 / 弹窗标题 | 宋体 + 字距 1–3px | 如 logo、留存目录、mm-title |

层级（px）：页面主标题 18（宋）· 列表标题 15.5（宋）· 正文 15（宋）·
功能文字 13 · 标签/说明 11–12 · 元数据 10.5（字距 .5–1px，弱化）。
元数据一律弱化为 `--text-3` 小字，不与正文争注意力。

## 4. 布局与留白

- 结构：侧边栏 232px ｜ 主区（首页目录 / 详情双栏 `1fr 380px`）｜ 底部播放栏 52px。
- 首页是**目录**不是看板：单列行 + 1px 分隔线；上传区是一条细虚线导入栏（非大卡片）。
- 间距阶梯：4 / 8 / 12 / 16 / 20 / 28 / 34。页面边距 34–48。
- 层级靠**排版与细线**建立：章节用 1px `--border` 分隔；重要分界（目录头）用 1px 墨色实线。

## 5. 圆角 / 描边 / 阴影

- 圆角：控件 2–3px（`--radius`），弹窗 6px。**不用大圆角卡片**。
- 描边：1px `--border`；输入框 1px `#C6BFAE`；虚线仅用于导入栏/占位。
- 阴影：仅弹窗与 toast 允许极轻阴影 `0 3px 14px rgba(41,40,36,.08)`；卡片/按钮**无阴影**。
- 无渐变、无玻璃拟态、无动效装饰。

## 6. 组件

- **按钮**：主按钮=复古棕底白字（圆角 3px）；ghost=透明底 1px 边灰褐字；
  hover 边与字转棕；disabled 45% 透明。按钮内图标 14px。
- **输入/选择**：白底 1px `#C6BFAE`；focus 边转棕，**不用发光环**。
- **复选框**：自定义 15px 方框（白底棕边）；选中=棕底暖白勾（SVG 背景）；禁用 45%。
- **分段控件**：1px 边框包裹，激活项浅棕底棕字。
- **列表行（目录）**：宋体标题 + 右侧弱化元数据 + 次行小字徽章；hover 暖底；无卡片边框。
- **徽章**：无底色小字（字距 1.5px），语义色字；不用胶囊色块。
- **Tab**：文字 + 1px 下划线（激活棕），不用胶囊/色块。
- **弹窗**：白面 1px 边 6px 圆角；头/脚 1px 分隔；设置页分板块（棕小字标题 + 细线）。
  弹窗头部控件间距统一 8px（间距阶梯）；成对的互斥/步进控件（如缩放 −/+）
  用 1px 边框合成为分段组，不各自散落。
- **Toast**：纸片式——暖白底 1px 边 + **左 2px 语义色条**（棕=中性/绿=成功/砖红=失败）+
  对应语义图标；底部居中，18ms 淡入上浮；不用深色大块。
- **角标**：后台任务完成待查看 = 按钮右上 7px 复古棕圆点（`.has-new`）。
- **思维导图（SVG）**：根节点=复古棕底暖白字；一级=强调浅底 `#EFEBE1` + 棕边 `#C9BFAE`；
  二级=白底 + 细边 `#E4E0D7`；连线 `#CFC7B4` 1.5px；节点圆角 3px；
  节点文字宋体、时间戳无衬线棕字；画布底 `#FBFAF6`（纸面），导出 PNG 同底。
- **状态符号**：6px 圆点（列表）/ 18px 图标（任务行）：完成绿、进行赭（spin）、失败砖红、排队灰。

## 7. 图标

遵循 `design/icons/spec.md`：24 网格、线宽 1.5、round cap/join、currentColor。
**禁止 emoji 与外部图标库**；新增图标先入 sprite 再登记映射表。
AI 功能禁用魔法棒/闪光/机器人套路（解读=页边批注线、随笔=文章页、脑图=节点树）。

## 8. 状态与动效

四态齐备：默认 / 悬停（转棕或暖底）/ 选中（棕或浅棕底）/ 禁用（45%）。
后台任务三态：进行中（按钮置灰 + 行内环 spinner）→ 完成（角标待查看）→ 失败（toast err）。

### 8.1 动效原则

动效只表达**状态与层级的变化**，不做装饰。安静如图书馆翻页：短、轻、减速落地，
无弹跳、无视差、无炫技。令牌：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--t-fast` | 160ms | 颜色/边框/填充/悬停/菜单 |
| `--t-base` | 260ms | 组件入场、toast、气泡、角标 |
| `--t-slow` | 360ms | 视图/弹窗/文本块入场 |
| `--ease-out` | `cubic-bezier(.25,.8,.3,1)` | 统一减速曲线：起势轻、落地绵 |

所有 transition/animation 的时长必须取自令牌，禁止散落硬编码；
悬停反馈一律 `--t-fast`，入场一律 `--t-base`/`--t-slow`。
禁止：弹跳/回弹曲线、视差、>4% 的放大、循环动画（功能性 `spin`/`pulse` 除外）。

### 8.2 场景清单

| 场景 | 动效 |
|---|---|
| 视图切换（首页 ↔ 详情） | fade-in 360ms |
| 弹窗打开 | 遮罩 fade 260ms + 卡片 rise-in(6px) 360ms；关闭即时 |
| 下拉菜单 | menu-in(−4px) 160ms |
| Tab 切换 | fade-in 260ms |
| Toast | rise-in 260ms |
| 目录行 | rise-in 360ms，逐行 stagger 30ms（封顶 10 行）；**仅显式渲染**（进入首页/切文件夹；搜索逐键刷新不动画），轮询刷新不动画 |
| 转写段落 | 渲染时 fade-in 360ms，前 18 段 stagger 26ms |
| 解读区块 | rise-in 260ms，逐块 stagger 50ms |
| 问答新消息 | 仅新气泡 rise-in 260ms |
| 按钮按压 | scale(.97)，跟 --t-fast |
| 角标出现 | pop-in 260ms；出现后静止，不循环 |
| 脑图渲染 | fade-in 360ms；节点填充 hover 160ms |
| 跳转原声 | 转写区 smooth scroll |
| 运行态 | 环 spinner / 状态点 pulse（仅允许的功能循环） |

### 8.3 无障碍

`prefers-reduced-motion: reduce` 时关闭全部动画/过渡/平滑滚动。
自检：新动效必须用令牌；轮询重渲染不得触发入场动画。

## 9. 文案语气

- 克制、安静、文学感；短句；不用感叹号轰炸与营销腔（「一键」「极速」「神器」禁用）。
- 功能名用名词短语（解读 / 随笔 / 札记 / 新标题）；提示语陈述事实（「任务已开始，完成后角标提醒」）。
- 高频操作放顶栏操作区（与其余顶栏按钮同排对齐），低频操作才进「⋯」菜单。
- 错误提示说原因与下一步（「目标文件夹不存在：…」），不指责用户。
- 品牌语句仅 *Quod manet, manet.*；不使用已废弃的 slogan。
